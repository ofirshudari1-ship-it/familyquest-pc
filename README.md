# FamilyQuest PC 🎮🪙

**Turn screen time into a game your kids actually want to win — by doing their chores.**

## What it does

FamilyQuest PC is a Windows desktop app that helps families turn the daily screen-time tug-of-war into something everyone enjoys. The computer starts locked, and your child earns "QuestCoins" by completing real-world tasks — homework, tidying their room, reading — then trades those coins in for computer time or rewards you set up yourself, like a pizza night, a movie, or a small toy. It's one app that runs entirely on your family's own computer: a locked kid's screen with a task board, a reward shop, streaks, and badges to keep things fun, plus a PIN-protected parent dashboard for creating and approving tasks, managing rewards, checking usage reports, and setting limits (including a separate weekend allowance and extra lockout windows, like study hours). Everything stays local and offline — there's no cloud account, no server, and no subscription; your family's data lives on your own machine.

## Download & install

Get the latest installer from the GitHub Releases page:

**[Download the latest version](https://github.com/ofirshudari1-ship-it/familyquest-pc/releases/latest)**

1. Download `FamilyQuest-PC-Setup-<version>.exe` from the release's Assets.
2. Run the installer and follow the setup wizard.
3. On first launch, set up your family: add each child, pick their daily (and optional weekend) screen-time limits, and choose a PIN for the parent dashboard.
4. Add a few starter tasks and rewards from the parent dashboard (accessible from the system tray icon, behind your PIN).
5. Your child's screen locks automatically when their time or tasks run out — no further setup needed.

**System requirements:** Windows 10/11.

## Key features

- **Locked kid's screen** with a task board, a reward shop, and streaks/badges to keep kids motivated — a full-screen countdown appears while a screen-time session is active.
- **PIN-protected parent dashboard** for creating and approving tasks, managing the reward shop, marking rewards as delivered, checking usage reports, and freezing a child's access instantly in an emergency.
- **Reward Shop** — set up any reward you like, not just screen time (a movie night, a favorite snack, a small toy); your child redeems it with coins and you mark it delivered once given.
- **Streaks and badges** — automatic coin bonuses for consecutive days with at least one approved task, plus achievements for milestones like a first task, a first purchase, or coins saved up.
- **Separate weekend time limits** and **named lockout windows** (like study hours) beyond the standard bedtime lock.
- **A leveling system** with titles that grow with lifetime coins earned, shown on your child's card and in the dashboard.
- **Weekly trend reports** you can print directly, and a "Home" dashboard tab summarizing every child's level, streak, balance, and status at a glance.
- **App activity awareness** — you can set a list of approved apps for game time; anything outside that list is quietly logged and gently flagged to your child rather than force-closed.
- Warm, modern design with a locally embedded font, subtle animations, and short sound effects for earning coins or completing tasks (all toggleable in Settings).

## Automatic updates

FamilyQuest PC checks GitHub for new versions automatically in the background and offers to install them for you, so you don't need to manually re-download the installer for routine updates. You can always find the latest release yourself on the [Releases page](https://github.com/ofirshudari1-ship-it/familyquest-pc/releases).

## Privacy

FamilyQuest PC is local-first: all family data — children's profiles, tasks, coins, and reports — is stored only on your own computer. There's no account, no cloud sync, and nothing about your family is sent anywhere. The parent dashboard is PIN-protected so kids can't get into settings on their own.
