# Watchdog (אופציונלי — הגנת "לא ניתן לסגור מ-Task Manager")

## מה זה עושה

יוצר שתי משימות מתוזמנות של Windows (Task Scheduler) שכל תפקידן הוא לנסות
להפעיל את FamilyQuest PC:

- **FamilyQuestPC-Watchdog-Logon** — בכל התחברות למשתמש.
- **FamilyQuestPC-Watchdog-Minute** — כל דקה, כל עוד המשתמש מחובר.

שתי המשימות רצות כ-`SYSTEM` עם `/IT` (Interactive Token) — כלומר Task Scheduler
מפעיל את התוכנה בתוך ה-session האינטראקטיבי של המשתמש המחובר, למרות שהמשימה
עצמה שייכת ל-SYSTEM. הפעלה חוזרת כשהתוכנה כבר פועלת היא פעולה חסרת נזק (התוכנה
מזהה שיש כבר עותק רץ ומתעלמת מהעותק החדש) — כך שבפועל המשימה "כל דקה" היא זו
שמחזירה את התוכנה תוך כדקה אם ילד סגר אותה דרך Task Manager.

## למה אי אפשר לבטל את זה בלי הרשאת מנהל

משימה מתוזמנת שנרשמה עם `/RU SYSTEM` דורשת הרשאות מנהל גם כדי לשנות וגם כדי
למחוק אותה. חשבון Windows סטנדרטי (לא מנהל) — שזה בדיוק החשבון שמומלץ להריץ בו
את הילד (ראו ה-README הראשי) — לא יכול לגעת בה דרך ממשק Task Scheduler ולא דרך
`schtasks`.

## התקנה

הרץ לחיצה כפולה על `Install-Watchdog.bat` **אחרי** שהתקנת את FamilyQuest PC
(דרך ה-Setup הרגיל). הסקריפט יבקש הרשאות מנהל (UAC) — זה תקין וצפוי.

## הסרה

הרץ `Uninstall-Watchdog.bat` (גם הוא דורש הרשאות מנהל).

## מגבלה ידועה

זו לא הגנה "בלתי ניתנת לעקיפה". ילד עם הרשאות מנהל על אותו מחשב יכול להיכנס
ל-Task Scheduler בעצמו ולמחוק את המשימות, או להסיר את התוכנה לגמרי. ההגנה
האמיתית היא ארכיטקטונית, לא טכנית: **הרץ את חשבון הילד כחשבון Windows סטנדרטי
(לא מנהל)** — ראו סעיף "הגדרה מומלצת" ב-README הראשי של הפרויקט.
